LuxStay Master Documentation

Comprehensive developer reference and customization guide for the commercial-grade LuxStay luxury hotel, resort, villa, and bespoke travel React 19 template.

1. Introduction & Overview

LuxStay is an ultra-premium, commercial-grade frontend web template crafted using React 19, Vite 8, Tailwind CSS v4, and React Router v7.

Engineered to satisfy the highest standards of luxury hospitality websites, LuxStay provides 8 curated concept homepages, a dedicated Master Landing showcase, over 38 inner page variations, centralized state management across 6 React contexts, interactive Leaflet maps, touch-enabled Swiper carousels, and a decoupled ES-module data layer.

🏨 8 Concept Homepages

Beach Sanctuary, Flagship Luxury Hotel, Resort & Spa, Travel Agency, Boutique Art Hotel, Luxury Villa & Chalet, Modern City Skyline, and Dark Luxury Heritage.

🗺️ 38+ Inner Variations

Multiple listing and detail layouts for Accommodations, Destinations, Expeditions, Michelin Dining, Resort Facilities, Lightboxes, Blogs, Contact, and VIP Auth.

🎨 Interactive Theme Studio

Floating customizer to live-switch Light/Dark modes, active font families, 4 Header styles, Sticky toggle, and 3 Footer variations on any page.

⚡ React 19 + Tailwind v4

State-of-the-art tech stack utilizing React 19 concurrent features, zero-config Tailwind v4 CSS `@theme` tokens, and lightning-fast Vite 8 HMR.

3. Quick Installation

  1. Unpack the Package

    Extract luxstay-theme.zip to your desired local workspace folder.

  2. Navigate to Directory

    Open your terminal / command prompt and change directory:

    cd luxstay-theme
  3. Install Dependencies

    Install all required node packages:

    npm install
  4. Launch Development Server

    Start the Vite development server with instant Hot Module Replacement (HMR):

    npm run dev

    Open http://localhost:5173 in your browser to view the application.

6. Centralized Routing (React Router v7)

Routing is managed via React Router DOM v7 in src/routes/AppRoutes.jsx using the modern createBrowserRouter API.

All pages render within MainLayout, which automatically injects the active Header, Footer, ScrollToTop, ThemeCustomizer, PagePopups, and SavedDrawer.

How to Add a New Page Route:

  1. Create your page component: Place it in src/pages/your-section/YourNewPage.jsx.
  2. Register in src/routes/AppRoutes.jsx: 
    import YourNewPage from "../pages/your-section/YourNewPage";

const router = createBrowserRouter([
  {
    path: "/",
    element: <MainLayout />,
    children: [
      // ... existing routes
      { path: "your-new-page", element: <YourNewPage /> },
    ],
  },
]);
  3. Add to Navigation: Add your new route item to NAV_LINKS inside src/constants/navigation.js to expose it in the header dropdowns and mobile slideout menu.

8. Global Context Architecture

LuxStay wraps the entire application tree in 6 React Context Providers in src/App.jsx and src/layouts/MainLayout.jsx:

1. ThemeContext

Manages Light/Dark color mode, font family switching, 4 Header styles, Sticky toggle, and 3 Footer variants. Persists in localStorage.

2. AuthContext

Simulates user sessions, member sign-in/registration, and 3 VIP Loyalty tiers (Silver, Gold, Black Card) with automatic member discounts.

3. BookingContext

Maintains global reservation state, selected room/tour, check-in/out dates, guest count, price calculation, and confirmation voucher generation.

4. FavoritesContext

Powers the luxury Wishlist system. Toggles suite/tour saves, updates header count badge, and renders the slideout SavedDrawer.

5. ToastContext

Delivers sleek, animated notifications for actions like copying promo codes, saving suites, submitting reviews, and booking confirmations.

6. PagePopupContext

Orchestrates contextual luxury popups per homepage (seasonal discounts, newsletters, private jet concierge) with customizable delays.

Provider nesting in src/App.jsx:

// src/App.jsx
export default function App() {
  return (
    <ThemeProvider>
      <ToastProvider>
        <AuthProvider>
          <FavoritesProvider>
            <BookingProvider>
              <AppRoutes />
            </BookingProvider>
          </FavoritesProvider>
        </AuthProvider>
      </ToastProvider>
    </ThemeProvider>
  );
}

Example: Adding an item to favorites and displaying a luxury toast

import { useFavorites } from "../hooks/useFavorites";
import { useToast } from "../hooks/useToast";

function SaveSuiteButton({ room }) {
  const { isFavorite, toggleFavorite } = useFavorites();
  const { addToast } = useToast();
  const saved = isFavorite(room.id);

  const handleSave = () => {
    toggleFavorite(room);
    addToast({
      title: saved ? "Removed from Wishlist" : "Saved to Wishlist",
      message: `${room.title} has been ${saved ? "removed from" : "added to"} your private collection.`,
      type: "success",
    });
  };

  return (
    <button onClick={handleSave}>
      {saved ? "❤️ Saved" : "🤍 Save Suite"}
    </button>
  );
}

The template features a complete, interactive client-side Wishlist System.

13. Promotional Popups System

Promotional modals are configured in src/data/pagePopups.js and managed by PagePopupContext.jsx.

Features include:

  • Contextual detection: Displays tailored promotions depending on the active homepage (e.g. 40% Off Beach Sanctuary for /home-beach, Palace Privilege Credit for /home-hotel).
  • Auto-trigger timer: Opens automatically after a polite delay (default 6 seconds).
  • Dismissal tracking: Remembers dismissed popups so visitors aren't repeatedly interrupted.
  • Floating Trigger Badge: Discreet bottom-left badge (PagePopupFloatingTrigger.jsx) allows visitors to reopen the promotion at any time.
  • Direct booking integration: Clicking "Book Now" opens the centralized BookingModal with the promo code pre-applied!

23. Headless CMS & Backend API Guide

Connecting LuxStay to a live backend (Strapi, Contentful, Sanity, Supabase, or REST API) is simple because all components consume clean JavaScript objects.

Example: Using TanStack Query with an external API

import { useQuery } from "@tanstack/react-query";
import axios from "axios";
import { ROOMS_DATA } from "../data/rooms";

export function useRooms() {
  return useQuery({
    queryKey: ["rooms"],
    queryFn: async () => {
      try {
        const { data } = await axios.get("https://api.yourhotel.com/v1/rooms");
        return data;
      } catch (err) {
        console.warn("API unavailable, falling back to local dataset", err);
        return ROOMS_DATA;
      }
    },
    initialData: ROOMS_DATA,
  });
}

  • Build Command: npm run build
  • Publish Directory: dist

Apache Web Server (Client-Side Routing .htaccess):

Place this .htaccess file inside your server root so React Router sub-routes resolve cleanly on page refresh:

<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>

Nginx Web Server Configuration:

server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/luxstay/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

26. Troubleshooting & FAQs

Q: Page refresh causes a 404 error on my production server?

This is standard behavior for single-page applications (SPAs). Configure URL rewriting on your web server to redirect all requests to /index.html (see Section 25 above).

Q: Dependency installation fails during npm install?

Ensure you are using Node.js v18.18+ or v20+. Delete your local node_modules/ folder and package-lock.json, then run npm install cleanly.

Q: How do I change the default currency symbol?

Open src/constants/theme.js and update SITE_CONFIG.currency (e.g., "$", "€", or "£").

29. Demo Limitations & APIs

Frontend Simulation Notice:
LuxStay is a 100% frontend React template. Reservation widgets, search queries, booking modals, and confirmation vouchers provide a frontend client-side simulation. No backend database or live payment gateway (e.g. Stripe, PayPal) is included by default. To process live payments, connect the modal submit handlers to your preferred booking or payment gateway API.
